DJ Booth v2: where does the library tree live?

Rip is now a tab behind the booth. Library is a collapsible tree with your own headings. Two ways to place it.

1

Tree as a collapsible sidebar

Library tree on the left, always visible while you play, with a handle to fold it away for a clean booth on the night. Drag a leaf onto a deck to load it.

Booth full-width, tree in its own tab

Booth takes the whole screen. The library is a Library tab (same tree) and a quick-search popup you summon with a key while playing, so you load without leaving the decks.
