# Bass Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The rip's `bass:` line is the loop the stem actually plays, found from a per-step pitch grid, written as short as it can be, scored against the stem, with any build material offered as a muted second line.

**Architecture:** In `service/algorip`, a new `bassgrid.py` (pyin pitch and onsets per 16th step) replaces Basic Pitch for bass; `loop.py` finds the period the bars repeat at with a two-pass vote and splits off the deviating bars' extra notes as a layer; `score.py` scores any candidate against the grid with a frame score and mir_eval's onset F1; `bass.py` runs the candidate search and packs the winner into a new `BassLoop` on `Analysis`; `generate.py` writes it. Fixtures are derived JSON from the cached Solomun stems and a synthetic build; a vitest test evaluates each golden's bass line with real Strudel and checks the events.

**Tech Stack:** Python 3.11 (numpy, scipy, librosa 0.11, mir_eval 0.8.2, pydantic 2), pytest; TypeScript, Solid, vitest with the @strudel bundles.

**Spec:** `docs/superpowers/specs/2026-10-20-bass-loop-design.md`

## Global Constraints

- Python `>=3.11,<3.12`; pins exact (`mir_eval==0.8.2` added to `service/pyproject.toml`); pytest runs with `--disable-socket --allow-unix-socket`; no network in tests.
- No audio is committed: fixtures are JSON and `.strudel` text.
- Generated lines are named (`bass:`, muted `_bass2:`); never `.orbit()`.
- Existing goldens `house`, `breaks`, `drums_only`, `sustain` produce byte-identical `.strudel` output after this work.
- Pitch tracking of a 60 s clip takes under 5 s on the M2 (design: resample to 11025 Hz, pyin fmin 30, fmax 400, frame 2048, hop 256).
- Constants with the design's values: `LOOP_AGREE = 0.8`, `LOOP_CORE_SHARE = 0.4` (the spec said 0.5; the Solomun clip has 4 core bars of 9, and the spec names that clip's loop as the authority), `LOOP_MIN_CORE = 2`, `LAYER_MIN_STEPS = 4`, `SIMPLER_TOLERANCE = 0.05`, `RMS_FLOOR = 0.02`, `VOICED_SHARE = 1 / 3`.
- Every commit ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and nothing else as a trailer.
- Run `cd service && uv run pytest -q` and, for app tasks, `pnpm exec vitest run` and `pnpm exec tsc --noEmit -p .` from the repo root before each commit.

## Review Focus

1. A silent or near-silent bass stem: no pitched step → `bass == []`, `bass_loop is None`, no exception anywhere in score or generate (Task 4 and Task 6 tests).
2. A clip of one or two bars: the loop finder needs two core bars, so a 1-bar clip gives `bass_loop None` and the verbatim line, without a crash (Task 2 test).
3. A bass whose fundamental is outside 30–400 Hz for some steps (sub-bass drop, a high fill): those steps are rests, not wrong pitches, and a note that was sounding ends there (Task 1 test with a 25 Hz note).
4. A bass that never repeats (four different bars): no loop, the verbatim bass line as today, and the Rip tab shows no loop text (Task 2, Task 5 and Task 8 tests).
5. A long pitched tail after a note (release or reverb): a step with no onset and the same pitch class sustains the note rather than starting a new one, so a plucked note is not written as a run of 16ths (Task 1 test).

### Task 2: The loop finder

**Files:**
- Create: `service/algorip/loop.py`
- Test: `service/tests/test_loop.py`

**Interfaces:**
- Consumes: nothing from the audio side; bars are `dict[int, H]` (step → hashable value), as `mini.consensus` uses.
- Produces:
  ```python
  LOOP_AGREE = 0.8; LOOP_CORE_SHARE = 0.4; LOOP_MIN_CORE = 2; LAYER_MIN_STEPS = 4
  LOOP_PERIODS = (1, 2, 4, 8)   # 8 only when len(bars) >= 16

  @dataclass
  class Loop(Generic[H]):
      period: int
      templates: list[dict[int, H]]        # one per phase
      core: list[int]                      # bar indexes agreeing with their template
      deviating: list[int]
      extra: list[dict[int, H]] | None     # the layer, one dict per phase of ITS OWN period (1 first)
      extra_bars: tuple[int, int] | None   # 0-based inclusive range of the deviating bars

  def agreement(bar: dict[int, H], template: dict[int, H]) -> float   # share of occupied steps agreeing; 1.0 when both empty
  def vote(bars: list[dict[int, H]], period: int) -> list[dict[int, H]]  # strict-majority template per phase
  def find_loop(bars: list[dict[int, H]]) -> Loop[H] | None
  ```
  `find_loop`: for each period in order, `vote` over all bars → core = bars with `agreement >= LOOP_AGREE`; re-`vote` over core bars only → recompute core and deviating; accept when `len(core) >= max(LOOP_MIN_CORE, LOOP_CORE_SHARE * len(bars))`. The layer: for each deviating bar, the steps whose value is absent from its template or differs; those per-bar dicts go through `find_loop` again (periods 1, 2, 4 only) and the result's templates become `extra`; if the deviating bars' extra steps average under `LAYER_MIN_STEPS` per bar, `extra` is None. `extra_bars` is `(min(deviating), max(deviating))`.

### Task 3: The scorer

**Files:**
- Create: `service/algorip/score.py`
- Modify: `service/pyproject.toml` (add `"mir_eval==0.8.2"` to dependencies; `uv lock` must not change any other pin)
- Test: `service/tests/test_score.py`

**Interfaces:**
- Consumes: `BassGrid`, `Note`, `Grid`.
- Produces:
  ```python
  @dataclass(frozen=True)
  class Score:
      frame: float
      onset_f1: float
      match: float   # round(0.5 * frame + 0.5 * onset_f1, 2)

  def expand(templates: list[list[Note]], bars: int) -> list[Note]   # the loop repeated: note i of phase p lands in every bar b with b % len(templates) == p
  def score(truth: BassGrid, grid: Grid, notes: list[Note], layer: list[Note] = ()) -> Score
  ```
  Frame: over steps where the truth is pitched or the candidate sounds (a note or layer note covering the step), the share where the truth is pitched and its pitch class is in the candidate's set of pitch classes on that step. Onset F1: `mir_eval.transcription.precision_recall_f1_overlap(ref_intervals, ref_pitches, est_intervals, est_pitches, onset_tolerance=grid.step_seconds / 2, pitch_tolerance=100.0, offset_ratio=None)[2]`, with every pitch folded to `midi % 12 + 36` before `librosa.midi_to_hz`; reference onsets are the truth's start steps, estimate onsets the notes' and layer's starts; intervals end at the next step boundary after the note. With no reference and no estimate onsets the F1 is 1.0; with one side empty it is 0.0.

- Produces:
  ```python
  # schema.py
  class BassLoop(BaseModel):
      period: int
      templates: list[list[Note]]            # per phase; every note has bar == 0
      layer: list[list[Note]] | None
      layer_bars: tuple[int, int] | None     # 1-based inclusive
      match: float
      match_with_layer: float | None

  # mini.py
  def template_note(heard: list[dict[int, Note]], step: int, pc: int) -> Note      # was _template_note
  def loop_mini(templates: list[list[Note]]) -> str                                  # cycle([notes_bar_mini(t) for t in templates])

  # bass.py
  SIMPLER_TOLERANCE = 0.05
  def transcribe_bass(y: np.ndarray, sr: int, grid: Grid, key: Key) -> tuple[BassGrid, list[Note]]
      # grid_to_notes, then snap_to_key, then fold_octaves into BASS_LOW..BASS_HIGH, as before; the BassGrid's midi are also snapped and folded so the truth matches the register
  def candidates(templates: list[list[Note]]) -> list[tuple[str, list[list[Note]]]]
      # [("a", as is), ("b", eighth grid), ("c", sustained), ("d", both)]; (b) moves an odd-step start to the nearest even step, merging into a same-pitch neighbour that starts there, dropping it when both even neighbours are taken; (c) merges a note into the previous one when they are adjacent and the same midi
  def choose_bass_loop(bg: BassGrid, grid: Grid, notes: list[Note]) -> BassLoop | None
  ```
  `choose_bass_loop`: per-bar dicts of `step → midi % 12` over the notes' starts → `find_loop`; None → None. Templates as Notes via `template_note` over the core bars. Layer notes likewise from the loop's `extra` (commonest midi and length among deviating bars). For each candidate: notation `loop_mini(c)`, `score(bg, grid, expand(c, grid.bars))`; winner = fewest characters among those with `match >= best - SIMPLER_TOLERANCE`, ties to the earlier letter. `match_with_layer = score(bg, grid, expand(winner, bars), expand(layer, bars)).match` when there is a layer.
