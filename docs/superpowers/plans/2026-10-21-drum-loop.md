# Drum Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The `drums:` and `hats:` lines are the loop the track plays, found by the loop finder per voice, with every hit the loop does not play offered as one muted `_fills:` line, and a hit-agreement number on the Rip tab.

**Architecture:** A new `service/algorip/drumloop.py` runs `loop.find_loop` over each drum voice's per-bar hit sets, with a drum-only rule against empty phases, and computes per-bar fills and an F1 match; `generate.py` writes the loops and the `_fills:` line from it, and `voice_mini` goes; `Analysis` gains a small `drum_summary` for the Rip tab. Melody and the bass fallback keep `mini.consensus` untouched.

**Tech Stack:** Python 3.11 (pydantic 2), pytest; TypeScript, Solid, vitest with the @strudel bundles.

**Spec:** `docs/superpowers/specs/2026-10-21-drum-loop-design.md`

## Global Constraints

- `generate` stays a pure function of `Analysis`; `drum_loops(a)` is deterministic.

## Review Focus

1. A voice with hits in only one bar of a long clip (one crash): the loop is empty at period 1, so the voice is off the main line and its hit is in `_fills:` at its bar (Task 1 test, Task 2 test).
2. A one-bar clip: `find_loop` needs two bars, so every voice is verbatim with no fills and match 1.0; no `_fills:` line (Task 1, Task 2).
3. No drum hits at all: no `drums:`/`hats:` lines, no `_fills:` line, `drum_summary` is None, the Rip tab shows nothing for drums (Task 2, Task 3).
4. A fill bar whose extra hits are all at steps the template also plays in other voices: fills are per voice, so nothing is lost or double-counted; the `_fills:` line names each voice as on its main line (snare as `cp` when the bank says so) (Task 2 test).
5. The snare voice `sd` written as `cp`: the fills part for `sd` must use `s.snare_name`, like the main line (Task 2 test).

### Task 1: Drum loops per voice

**Files:**
- Create: `service/algorip/drumloop.py`
- Test: `service/tests/test_drumloop.py`

**Interfaces:**
- Consumes: `loop.find_loop(bars: list[dict[int, H]], periods=...) -> Loop | None` with `Loop.period`, `Loop.templates: list[dict[int, H]]`; `Analysis.drums: dict[str, list[tuple[int, int]]]`, `Analysis.bars`.
- Produces:
  ```python
  VOICE_LINES: dict[str, tuple[str, ...]] = {"drums": ("bd", "sd"), "hats": ("hh", "oh")}

  @dataclass
  class VoiceLoop:
      period: int
      templates: list[set[int]]   # one per phase; all empty when the voice has no regular part
      fills: list[set[int]]       # one per clip bar: hits the loop does not play there

  @dataclass
  class DrumLoops:
      voices: dict[str, VoiceLoop]         # only voices with any hit
      fill_bars: tuple[int, int] | None    # 1-based inclusive, over all voices; None when no fills
      match: float

  def voice_loop(bars: list[set[int]]) -> VoiceLoop
  def drum_loops(a: Analysis) -> DrumLoops
  ```
  `voice_loop`: `find_loop([dict.fromkeys(b, True) for b in bars])`; when the loop has a phase whose template is empty while some bar of that phase has hits, retry with `periods` restricted to those shorter than the found period; when no period qualifies, or `find_loop` returns None: if the clip has at least two bars and the period-1 `vote` is empty, `templates = [set()]`, period 1 (no regular part); otherwise verbatim: `period = len(bars)`, `templates = bars`. `fills[b] = bars[b] - templates[b % period]` for every bar. `match`: over all voices, the F1 between the set of (voice, bar, step) the loops play (templates expanded) and the classified set; 1.0 when both are empty; rounded to 2 decimals.

**Interfaces:**
- Consumes: `drum_loops`, `bar_mini(name, steps)`, `cycle(parts)`.
- Produces:
  ```python
  def drum_lines(a: Analysis, s: SoundChoice) -> list[str]
  ```
  `drums:` and `hats:` lines as today, each voice's part now `cycle([bar_mini(name, t) for t in loop.templates])`, a voice with all-empty templates left off the line, a line with no parts omitted. Then, when `fill_bars` is not None: `// bars {lo}–{hi} add these hits (a fill): remove the underscore to hear them` and `_fills: s("<parts>").bank("{s.drum_bank}")` where parts are, in `bd, sd, hh, oh` order for voices with any fill, `cycle([bar_mini(name, f) for f in loop.fills])` with `name` as on the main line (`sd` → `s.snare_name`). `generate` uses `drum_lines` in place of the two `_drum_line` calls.
